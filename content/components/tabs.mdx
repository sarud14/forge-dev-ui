## When to use

Use Tabs to switch between mutually exclusive panels in the same view. Do not use them as page navigation.

## API

`items` is `{ value, label, content, disabled? }[]`. `defaultValue` / `value` / `onValueChange` follow Radix. `aria-label` names the tablist.

## Accessibility

Tablist, tab, and tabpanel roles come from Radix. Arrow keys, Home, and End move between tabs.
