## Source of truth

Token files are split by concern: color, spacing, radius, typography, breakpoints, elevation, motion. Tailwind maps utilities onto those custom properties. A class like `bg-background` and a `var(--color-background)` reference resolve to the same value.

## How to change a value

Edit the token file. If a new utility class is needed, map it in the Tailwind theme next. Do not patch a component with an arbitrary `text-[13px]` or `bg-[#fdeaec]` — if the value repeats, it belongs in the token set.
